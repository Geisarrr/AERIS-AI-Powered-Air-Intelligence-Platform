# AERIS

> Know Your Air. Protect Your Day.

AERIS is an AI-powered air intelligence platform for monitoring,
forecasting, analyzing, and understanding air quality.

## Architecture

- Frontend: Next.js + React + TypeScript
- Backend: FastAPI
- Database: PostgreSQL + PostGIS
- ML: XGBoost, Isolation Forest, SHAP
- Geospatial: Mapbox, GeoPandas, Shapely
